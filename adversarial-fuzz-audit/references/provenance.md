# Provenance: who wrote the code and who wrote the tests

Responsibility drives routing (Phase 2) and attribution (Phase 8). Get it right before
anything else.

## Signals, strongest first

1. **User statement.** "Codex wrote this, I wrote the tests." Record it verbatim with
   `source: user`.
2. **Commit trailers.** Agents sign their commits. Known patterns:
   - `Co-Authored-By: Claude <noreply@anthropic.com>` and variants naming a Claude model;
     `Claude-Session: https://claude.ai/code/session_...`
   - `Co-authored-by: Codex <...>` / `Co-authored-by: openai-codex[bot]` / `Co-Authored-By: ChatGPT`
   - `Co-authored-by: Copilot <...>` / `copilot-swe-agent[bot]` / `GitHub Copilot`
   - `Co-authored-by: Gemini` / `gemini-cli` / `google-labs-jules[bot]`
   - `Co-authored-by: aider <...>` and commit messages starting with `aider:` or `feat: ... (aider)`
   - `Co-authored-by: Cursor <...>` / `cursoragent`
   - `Co-authored-by: Devin` / `devin-ai-integration[bot]`
   - `🤖 Generated with [Claude Code]`, `Generated by Codex`, `Made with Cursor`
3. **Author identity.** Bot accounts (`*[bot]`, `noreply@anthropic.com`, `noreply@openai.com`)
   as the git author rather than co-author.
4. **Conversation context.** The agent that is running right now summarized "I implemented X
   and added tests". That agent is the author of both, including when the agent is you.
5. **Stylistic fingerprints** (weak, use only to raise a question, never to conclude): identical
   comment style across code and tests, test names that mirror implementation function names
   one-to-one, a test file created in the same commit as the implementation with the same
   trailer.

## Running the script

```bash
python3 scripts/provenance.py <repo-root> [path ...] --json adversarial/01-provenance.json
```

It walks `git log --format` for each path, classifies every commit by the patterns above,
aggregates per file, and prints a matrix:

```
file                              kind    author_guess   confidence  evidence
src/pagination.py                 code    claude         high        trailer:Co-Authored-By: Claude (3 commits)
tests/test_pagination.py          test    claude         high        trailer:Co-Authored-By: Claude (3 commits)
src/legacy/util.py                code    human          medium      author:dev@example.com
```

Test files are detected by path (`test_*.py`, `*_test.go`, `*.spec.ts`, `__tests__/`,
`src/test/java`, `tests/`) and by content fallback (imports of pytest, jest, junit, testing).

## Interpreting the matrix

- **Same high-confidence agent on code and tests** is the canonical case. The adversary must
  be another model.
- **Mixed authorship inside one file** (human started, agent finished): the file's claim is
  attributed to the agent for the parts it touched; use `git blame -w` on the specific
  functions when attribution matters for the report.
- **Unknown**: ask the user. Do not route until you know, because routing to the author
  silently is the failure mode this skill exists to prevent.
- **No git**: ask the user; if they do not know, record `author_guess: unknown` and treat the
  current session's model as a *possible* author, which forbids using it as adversary unless
  the user decides otherwise.

## Recording the result

`adversarial/01-provenance.json`:

```json
{
  "code_authors": ["claude"],
  "test_authors": ["claude"],
  "source": "git-trailers",
  "confidence": "high",
  "files": [ { "path": "src/pagination.py", "kind": "code", "author": "claude" } ],
  "notes": "Single feature commit abc123 with Claude trailer; tests added in same commit."
}
```

The report's independence statement is generated from this file plus the routing decision,
so keep it accurate even when the answer is embarrassing ("the current session wrote both").
